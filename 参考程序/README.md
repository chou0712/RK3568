# 卫星天线控制上位机（桌面版）

室内电脑运行的标签页式上位机，通过 UDP 与 RK3568 通信。
转台命令使用 HZZT-2-3kg 的 AA 协议，由 RK3568 透传到 RS422 转台。

## 默认通信参数

- RK3568 IP：`192.168.1.101`
- 发送端口：`20003`
- 接收端口：`20003`

发送和接收使用同一 UDP 端口。TLE/九轴辅助数据也走接收端口，不再单独设置
TLE 接收端口。

## 界面标签页

### 1 转台控制

- 转台复位：发送 02 定点命令到方位 `0°`（正北）、俯仰 `90°`（天顶）
- 定点运动：输入方位/俯仰，发送一次 02 定点命令
- 停止、状态查询
- 显示当前方位、俯仰、两轴速度、故障码、北向校准状态

### 2 过境预报

- 输入 TLE、观测站纬度/经度/海拔
- 计算未来 24 小时过境
- 显示开始时间、结束时间、持续时间、最大俯仰角、最大俯仰时间、最大方位角
- 设置“起始跟踪俯仰角”
- 选中过境后加入任务列表，不会自动跳转到任务页

### 3 TLE连续跟踪

- 每 150ms 用当前时间重新计算 TLE
- 使用 02 连续定点帧驱动转台
- 卫星俯仰角达到设定阈值后才开始跟踪
- 低于阈值时停止并等待，重新升起后自动恢复
- 不再提供 03 跟踪帧选项

### 4 任务管理

- 任务按开始时间排序
- 到达任务开始时间后自动执行，无需手动点击
- 一个任务结束后自动执行下一个任务
- 可删除任务或清空任务
- 查看每秒状态日志和 UDP 原始报文

### 底部状态栏

持续显示当前时间、方位、俯仰和连接/故障状态。

## 转台 AA 协议

```text
AA | 长度(1字节) | 设备ID(01) | 命令 | 参数/子命令 | 校验和(1字节)
```

- 多字节数据大端
- 角度/速度单位 0.1（实际值 × 10）
- 校验和：`sum(校验字节前所有字节) & 0xFF`

当前固件已验证 02 定点帧能驱动转台，因此所有连续跟踪统一使用 02 连续定点。

## 辅助数据

辅助数据使用：

```text
EB 90 | 长度(2字节，大端) | type(1字节) | 数据 | 校验和(1字节)
```

- `type=0x11`：TLE 两行 ASCII
- `type=0x12`：九轴 yaw/pitch/roll，三个 float32 大端

辅助数据发往接收端口（默认 20003）。
