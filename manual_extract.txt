1  CPG-3568 的基本特性

1.1 什么是可乐派CPG-3568

   可乐派CPG-3568 采用了瑞芯微RK3568 四核64 位Cortex-A55 ARM 处理器，基于高端22nm

工艺打造，主频最高可达2.0GHz，集成ARM Mali-G52 2EE GPU，内嵌高性能3D 和2D 图像加速

模块，内置1Tops 算力的AI 加速器NPU，可支持2GB/4GB/8GB 内存，具有4K 显示处理能力。

   可乐派CPG-3568 引出了相当丰富的接口，包括HDMI 输出、MIPI 摄像头、FPC 接口的PCIe2.0、

千兆网口、USB2.0、USB3.0 接口和40-Pin 扩展排针(I2S、CAN、I2Cx2、UARTx5、PWMx2、SPI、

GPIO 接口)。可广泛适用于高端平板、边缘计算、人工智能、云计算、AR/VR、智能安防、智能家

居等领域，覆盖AIoT 各个行业。CPG-3568 支持Android11、Ubuntu20.04(5.10 内核)、Debian11、

LinuxQT 等操作系统。


1.2 可乐派CPG-3568 的用途

  我们可以用它实现：


 • 一台Linux 个人桌面计算机

 • 一台Linux 网络服务器

 • Android 智能平板

 • Android 炫酷游戏机


   当然，可乐派CPG-3568 还有其他众多功能。它依托强大的生态系统以及各式各样的扩展配件，能

够助力用户轻松达成从创意构思到原型制作，再到批量生产交付的全过程。无论是充满奇思妙想的创

客、怀揣梦想的梦想家，还是热衷于自己动手的DIY 爱好者，可乐派CPG-3568 都是开展项目的理想

平台。

4  Linux SDK 使用说明

4.1 SDK 简介

   瑞芯微通用Linux SDK 工程，适用于以Rockchip 处理器为主芯片的可乐派系列板卡。整个SDK

工程，目录包含有buildroot、debian、app、kernel、u-boot、device、external 等目录。每个目录或其

子目录会对应一个git 工程，提交需要在各自的目录下进行。

 • app：存放上层应用app，主要是qcamera/qfm/qplayer/settings 等一些应用程序，在buildroot

   构建时会使用到这些程序

 • buildroot：基于buildroot 开发的根文件系统

 • debian：Debian 根文件系统构建脚本

 • device/rockchip：存放各芯片板级配置和Parameter 文件，以及一些构建与打包固件的脚本和预

   备文件

 • external：存放第三方相关仓库, 包括音频、视频、网络、recovery 等，在buildroot 构建时将会

   用到

 • kernel：存放kernel 源码

 • prebuilts：存放交叉编译工具链

 • rkbin：存放Rockchip 相关的Binary 和工具

 • rockdev：存放编译输出固件

 • tools：存放Linux 和Windows 操作系统环境下常用工具

 • u-boot：存放进行开发的uboot 代码


4.2 SDK 开发环境搭建

4.6.1 ADB 推送

   使用adb 命令编写的bat 脚本将SDK 编译成功的内核推送到主板

bat 脚本路径: 可乐派网盘->CPG-3568-> 工具软件->adb-linux-bat



@echo off
chcp 65001



REM 更新镜像
adb push ./boot.img /mnt
adb push ./recovery.img /mnt
adb push ./uboot.img /mnt


adb shell "dd if=/mnt/boot.img of=/dev/mmcblk0p3"
adb shell "dd if=/mnt/recovery.img of=/dev/mmcblk0p4"
adb shell "dd if=/mnt/uboot.img of=/dev/mmcblk0p1"

REM 更新wifi.ko
REM SDK中aic8800_bsp.ko所在目录如下
REM kernel/drivers/net/wireless/aic8800/aic8800_bsp
REM SDK中aic8800_fdrv.ko所在目录如下
REM kernel/drivers/net/wireless/aic8800/aic8800_fdrv


adb push ./aic8800_bsp.ko /system/lib/modules
adb push ./aic8800_fdrv.ko /system/lib/modules

REM 重启
adb shell "sleep 5 && echo +150000 > /sys/class/rtc/rtc0/wakealarm"
adb shell "poweroff -f"

echo "升级完成，请重启"
pause

  最常见的读写GPIO 方式就是用GPIO sysfs interface，通过操作/sys/class/gpio 目录下的export

bank = 3;

group = 1;
// GPIO3_B0 => 1, group ? {(A=0), (B=1), (C=2), (D=3)}
X = 1;

6.5.1 ADB 推送

   使用adb 命令编写的bat 脚本将SDK 编译成功的内核推送到主板

bat 脚本路径: 可乐派网盘->CPG-3568-> 工具软件->adb-android-bat



@echo off
chcp 65001

REM 更新镜像
adb root
adb remount
adb push ./boot.img /mnt/boot.img
abd push ./recovery.img /mnt/recovery.img
adb push ./uboot.img /mnt/uboot.img


adb shell "dd if=/mnt/boot.img of=/dev/block/by-name/boot"
adb shell "dd if=/mnt/recovery.img of=/dev/block/by-name/recovery"
adb shell "dd if=/mnt/uboot.img of=/dev/block/by-name/uboot"
adb shell "sleep 5 && echo +150000 > /sys/class/rtc/rtc0/wakealarm"
adb shell "reboot -p"

echo "升级完成，请重启"
pause
