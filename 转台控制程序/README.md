# HZZT-2-3kg 转台控制程序

这是一个面向 Windows 上位机的图形化控制程序。程序通过 UDP 与 RK3568 上的 `turntable-gateway.service` 通信，由 RK3568 使用 `115200 8N1`、四线全双工 RS422 控制转台并把原生状态帧回传给上位机。Windows 版只使用 Python 标准库，不要求安装 `pyserial`。

默认网络参数：

| 项目 | 地址 |
|---|---|
| RK3568 网关 | `192.168.1.101:20003` |
| Windows 上位机 | `192.168.1.102:20003` |

每个 UDP 数据报承载一个完整的转台原生 `AA` 协议帧。程序启动后会自动连接 RK3568 并查询转台状态。

## 运行

1. 确认电脑有线网卡为 `192.168.1.102/24`，能够 Ping `192.168.1.101`。
2. 安装 Python 3.10 或更高版本，并在安装时勾选加入 PATH。
3. 双击 `启动转台控制器.bat`，或在当前目录执行：

   ```powershell
   python turntable_control.py
   ```

4. 无实机时可先验证界面和基本流程：

   ```powershell
   python turntable_control.py --demo
   ```

使用其他地址或端口时：

```powershell
python turntable_control.py --gateway 192.168.1.101 --gateway-port 20003 --local 192.168.1.102 --local-port 20003
```

如果只想打开界面而不自动连接：

```powershell
python turntable_control.py --no-auto-connect
```

## 接线

USB-RS422 转换器接在 RK3568，而不是接在 Windows 上位机。必须使用四线全双工转换器：

| RK3568 侧 USB-RS422 | 转台底部 RS422B |
|---|---|
| TX+ | 8 脚 RX+ |
| TX- | 9 脚 RX- |
| RX+ | 6 脚 TX+ |
| RX- | 7 脚 TX- |
| GND | 10 脚 GND |

首次运行前应确认机械范围内无人、无线缆和工具，负载已经固定，并可随时切断 24 V 电源。程序中的“停止”不能替代物理断电或急停。

## 已实现功能

- RK3568 UDP 网关自动连接、断开和原始十六进制日志。
- 一帧一数据报传输、来源端点限制、累加和及协议长度校验。
- 状态查询、故障查询、驱动器状态查询。
- 15 字节和 16 字节状态帧兼容，连续字节流重同步和累加和校验。
- 实时显示两轴角度、速度和故障位；出现故障时自动发送停止。
- 定点、双轴步进、方位步进、顺/逆时针周扫、空间扫描、停止。
- 方位 `0～360°`、俯仰 `0～90°`和默认 `30°/s`安全范围校验。
- 运动命令发出后 1 秒未收到有效状态时自动停止，可在界面取消该看门狗。
- “基本控制”页提供设备复位；执行时先停止并锁定，150 ms 后发送复位帧，再自动查询状态。
- 设置零点和设备复位均有二次确认。
- 协议存在歧义的速度设置被单独放在“维护与待验证功能”页，并要求人工确认。

## 协议限制

- 速度设置帧在协议中写为长度 `0x09`，但按实际字段数应为 `0x0B`。界面默认 `0x0B`，也保留 `0x09`供抓包验证；未确认前不要在正式工况使用。
- 负向步进按有符号 16 位补码编码，符合方向说明，但原协议的数据类型栏写成 `uint16_t`。首次只应在安全位置使用极小步距验证。
- 状态上报的长度字段为 `0x10`，现有实机样帧只有 15 字节；解析器同时兼容 15 和 16 字节。
- 俯仰轴始终按任务书中的机械范围 `0～90°`限制，不采用协议表中个别位置出现的 `0～360°`。

## 测试

```powershell
python -m unittest -v test_turntable_control.py
```

测试覆盖文档中的全部快速命令样例、校验和、负向步进编码、状态解析、分段串口读取和错位重同步。

测试还覆盖 RK3568 UDP 往返传输、状态帧长度兼容和设置查询应答的异常长度字段。

## RK3568 板端要求

```bash
systemctl is-active turntable-gateway.service
systemctl is-enabled turntable-gateway.service
ss -lun | grep 20003
```

正常结果应为 `active`、`enabled`，并监听 `192.168.1.101:20003`。网关只接受来自 `192.168.1.102` 的控制数据报。
